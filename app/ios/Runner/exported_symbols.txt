# ("abort_could_not_find_entry_point___debug_dylib").

# Bản Debug KHÔNG dùng danh sách này nữa (bỏ EXPORTED_SYMBOLS_FILE khỏi cấu hình
# Debug trong project). Từ Xcode 26, bản Debug còn dựng thêm `__preview.dylib`
# cho Xcode Previews, và nó dùng chung danh sách export của target — mà trình
# liên kết coi mọi tên trong danh sách là "initial undefine", tức là bắt buộc

# thẳng bản Debug: "Undefined symbol: _main, referenced from <initial-undefines>".
# Bỏ danh sách khỏi Debug là xong: không strip thì mọi symbol đều còn, Dart vẫn
